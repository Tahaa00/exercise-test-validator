# Array Max (plain build)

Implement `public static int max(int[] values)` in the class `com.example.arraymax.ArrayMax`.

1. [task][Maximum of an array](maxOfMixedValues,maxOfNegativeValues,maxOfSingleValue,maxAtLastPosition)
   Return the largest value in `values`. The array may contain negative numbers and duplicates.
   Do not modify the array.

2. [task][Invalid input](emptyArrayIsRejected,nullArrayIsRejected)
   If `values` is `null` or empty, throw an `IllegalArgumentException`.
   The exception message is up to you; it is not graded.
